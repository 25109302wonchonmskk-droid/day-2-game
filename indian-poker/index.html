상대가 들어오기를 기다리는 중…
방을 만든 사람과 참가한 사람이 각자 기기에서 플레이합니다. 상대가 없으면 AI와 하기.
상대– 베팅 0
팟0
나– 베팅 0
규칙
  • 각자 3장: 나만 보기 1장(내 화면에만), 공개 1장(둘 다 봄), 머리 위 1장(상대 화면에만, 나는 못 봄).
  • 판마다 참가비 20, 베팅 1라운드. 레이즈 금액은 직접 정합니다(최소 10, 한 판에 레이즈 최대 4회).
  • 점수 = 3장 숫자의 합. A=1, 2~10은 그 숫자, J=11, Q=12, K=13. 무늬는 상관없습니다. 합이 큰 쪽이 이기고 같으면 팟을 나눕니다.
  • 콜로 끝나면 모든 카드가 공개되고 승패가 정해집니다. 먼저 행동하는 사람은 판마다 바뀝니다.
  • 온라인 대전은 두 기기가 직접 연결됩니다. 비공개 카드는 그 카드를 볼 수 있는 기기에만 존재합니다.
